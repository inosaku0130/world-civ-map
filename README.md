# WORLD CIVILIZATIONS ヘックス世界地図（Webサイト版）

外部と通信して、世界のニュース・地震・自然災害・統計を自動で取り込み続ける版です。
サーバーの契約やAPIキーは不要で、無料の静的ホスティング（GitHub Pages など）で動きます。

## 入っているもの

| ファイル | 役割 |
|---|---|
| `index.html` | サイト本体（地図・戦況・ニュースのピン） |
| `news.json` | ニュースの集約ファイル。下のスクリプトが自動で書き換える |
| `places.json` | 見出しから場所を推定するための地名辞書 |
| `scripts/fetch-news.mjs` | RSS（NHK・BBC・CNN・AFPBB の日本語版）を集めて `news.json` を更新 |
| `.github/workflows/news.yml` | 上のスクリプトを20分ごとに自動実行する設定（GitHub Actions） |

## 取り込みの仕組み

- **ブラウザから直接取得**（ページを開いている間ずっと）
  - USGS：M5以上の地震（2分ごと）
  - NASA EONET：火山・暴風雨・洪水（30分ごと）
- **サーバー側で定期取得**（誰も開いていなくても動く）
  - GitHub Actions が20分ごとにRSSとGDELTを読み、`news.json` を更新 → ページが2分ごとに読み直す
  - 同じタイミングで世界銀行APIからGDP・人口・軍事費の最新値を取り、`stats.json` に保存

## 公開の手順（GitHub Pages）

1. GitHub のアカウントを作り、新しいリポジトリを **Public** で作る。
2. このフォルダの中身（`index.html` `news.json` `places.json` `scripts` フォルダ）をリポジトリにアップロードする。
4. リポジトリの設定の「Pages」で、公開元を `main` ブランチのルートにする。
5. 設定の「Actions」で、ワークフローの権限を「読み取りと書き込み」にする。
6. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される。
7. 「Actions」タブで「ニュース更新」を一度手動実行し、緑のチェックが付くか確認する。

Netlify や Cloudflare Pages などに置いても `index.html` は動きます。その場合、RSSの定期取得だけ別の方法が必要です（ブラウザからの直接取得はそのまま動きます）。

## 知っておくこと

- ニュースの場所は見出しの地名からの自動推定で、ずれることがあります。地名が見出しにないニュースはピンになりません。
- 表示するのは見出しと出典リンクだけです。本文は各報道機関のサイトで読みます。
- 戦況（前線・占領地）は自動更新されません。`index.html` 内の `WARS` を書き換えると更新できます。
- RSSのURLは配信元の都合で変わることがあります。`scripts/fetch-news.mjs` の `FEEDS` を直してください。
- GitHub の定期実行は混雑時に遅れます。また、リポジトリが長期間まったく更新されないと停止されることがあります。
